# PAC-MAN — Level 1

A complete, self-contained Pac-Man game in a single HTML file. No installation,
no build step, no internet required.

## How to play

1. **Double-click `index.html`** — it opens in your web browser (Chrome, Edge,
   Firefox, Safari, anything).
2. Click **PLAY**.

That's it. There is nothing to install.

## Controls

| Action | Keys |
| ------ | ---- |
| Move   | Arrow keys **or** `W` `A` `S` `D` |
| Pause  | `P` |
| Start / restart | `Enter` or `Space` |

On a touchscreen or trackpad you can also **swipe** to steer.

## Features

- **Classic 28×31 maze** with the authentic double-line wall look.
- **Four ghosts with real AI** — each behaves differently, just like the arcade:
  - 🔴 **Blinky** chases you directly.
  - 🩷 **Pinky** aims four tiles ahead of you to cut you off.
  - 🩵 **Inky** uses Blinky's position to flank you.
  - 🟠 **Clyde** chases from far away but bolts for his corner up close.
- **Scatter / chase waves** — ghosts periodically retreat to their corners,
  then hunt again.
- **Power pellets** turn the ghosts blue and edible. Eat them in a chain for
  **200 → 400 → 800 → 1600** points. They flash white as the effect runs out.
- **Bonus fruit** 🍒 appears as you clear dots.
- **Animated everything** — chomping Pac-Man, wiggling ghost skirts, darting
  eyes, a shrinking death animation, and a pulsing power pellet.
- **Procedural sound** generated in the browser (toggleable) — no audio files.
- **Score, high score (saved locally), lives, and `READY!` round intros.**

Clear every dot to win the level. Get caught by a non-edible ghost and you lose
a life — run out of lives and it's game over.

Enjoy! 🟡
